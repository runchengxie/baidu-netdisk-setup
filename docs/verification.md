通过已登记的本地 MCP，调用本项目保护层包装的官方上传 SDK，完成 2 GiB + 17 字节、513 片上传。云端大小一致，首片、中间片和尾片下载后的 MD5 均与本地对应分片一致。本轮没有完整下载后计算 SHA-256；此前完整 SHA-256 成功的是官方 API 续传测试脚本。本轮云端测试文件、空目录和本地合成文件均已清理，未清空网盘回收站。本地 MCP 仍没有持久化断点续传功能。

本项目对官方 SDK 的预创建和最终创建调用设置 `rtype=0`，显式允许覆盖时设置 `rtype=3`。上游源码文件未改动。两个不同内容的同名上传并发实测只有一个成功，另一个返回冲突，下载与成功方内容一致；本次没有刻意制造越过预检查后的服务端竞态。

批量复制混入不存在的源文件时，本次未产生任何目标文件。检查实际状态后，仅补交缺少的两个预期文件，恢复成功，测试目录已清理。此结果不证明所有批量操作都具有原子性；本次未观察到部分成功。

另检查了一页既有文档，其 `content` 和 `abstract` 全为空，尚没有选出可确认已生产内容索引的样本。不能因此认定账号没有索引，也没有将内容搜索改记为通过。

## 自动刷新验证补充

2026 年 10 月 10 日在两个 MCP 保持连接时运行真实刷新检查：新令牌已加密保存，同一账号验证通过；远程启动程序在一分钟轮询中发现授权变化，更新桥接连接并完成初始化，后续读取成功。本地工具后续调用使用可更新的授权入口，接口返回空间已满，容量查询也显示使用量超过当前额度。本轮不因此扩大为完整上传通过；测试目录与本地样本已清理。

日志在格式化及写入前脱敏，实测日志检查没有命中已知令牌的全文或首尾片段。失败授权、错误密钥、网络失败、过期时间与并发交换使用人工测试材料，不撤销或替换真实应用密钥。远程协议测试证明已执行的写入不重放，更新等待请求结束，取消通知仍可转发。

本轮验证包含 28 项 Python 单元测试和 3 项 Node 协议测试，另有 PowerShell、Python、Node 语法检查。授权检查期限使用人工时钟验证，未进行连续三十天等待自然到期的测试。
