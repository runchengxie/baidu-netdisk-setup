本项目对官方 SDK 的预创建和最终创建调用设置 `rtype=0`，显式允许覆盖时设置 `rtype=3`。上游源码文件未改动。两个不同内容的同名上传并发实测只有一个成功，另一个返回冲突，下载与成功方内容一致；本次没有刻意制造越过预检查后的服务端竞态。
